git-explain-tui is a terminal interface for investigating Git history and asking focused AI questions about the commit, file, or range you have selected.

01 · Install

Get to your first commit in a minute.

The standalone installer is the simplest route on macOS and Linux. It needs Git, but not Python, uv, or pip.

Standalone
curl -fsSL https://raw.githubusercontent.com/mmcs-work/git-explain-tui/main/install.sh | sh
cd /path/to/a/git-repository
git-explain-tui

If you already use Python tooling, either option installs an isolated command:

uv tool install git-explain-tuipipx install git-explain-tui

Run git-explain-tui -h for options, or pass a repository path directly: git-explain-tui /path/to/repository.

04 · A guided tour

Five panes, one investigation loop.

  1. 01 · BranchesUse arrows to select a branch. Press Enter to load its commits, files, and diff into the other panes. This changes only the view—it never checks out the branch or changes the working tree.
  2. 02 · CommitsMove through the loaded history with j/k. Use / to filter by message, SHA, author, or ref.
  3. 03 · FilesPress f to choose one changed file. Select [all files] to return to the full commit view.
  4. 04 · DiffPress d to focus the colorized diff. Scroll vertically with j/k, and pan long lines with h/l or ←/→.
  5. 05 · ChatUse Tab or Ctrl+g, then h, to reach the question field. Conversations are scoped to the selected change.

05 · Find and navigate

Search the right thing in the right pane.

Filter commits

Focus Commits and press /. The filter matches subject, SHA, author, and Git decorations. Arrow keys move through matching commits while the filter is open. Press Enter to keep the filter, or Esc to cancel editing. Clear the query and press Enter to show all history.

Search the diff

Outside Commits, / searches the displayed diff. Press Enter to run the search, then n or N for the next or previous match. Matching lines are highlighted and the count appears in the Diff header.

Long commit messages and diff lines do not wrap into another pane. Pan Commit or Diff with h/l or ←/→, use H/L for a larger step, and press 0 to reset.

06 · Context modes

Send only the evidence your question needs.

Press m to cycle modes. The status line estimates context size before the first send, so you can balance cost and detail.

summary

Commit metadata, file list, and statistics. Best for a cheap overview.

patch

The complete selected commit patch. Use when changes interact across files.

file

Only the selected file diff. This is the default and is ideal for focused code questions.

range

An inclusive commit range and its combined diff. Chosen automatically for a selected range.

Inspect before sending

Press v outside the Chat editor to open an LLM Context Preview. It displays the exact Git context sent with the next request. Use arrows, Page Up/Down, or Home/End to inspect it.

In file mode, [all files] intentionally sends a summary—not every patch. Select one file for its diff, or choose patch for the complete commit.

07 · Request lifecycle

Know exactly what reaches a model.

  1. System instructionThe model is asked to act as a code-review companion, cite changed paths and lines where possible, and distinguish patch facts from inference.
  2. Selected Git contextThe summary, patch, focused file, or range is sent separately from your question. Press v to inspect this exact portion.
  3. Saved conversationOn follow-ups, prior user and assistant messages for the same scope are included. Local error messages are not sent to the provider.
  4. Your questionThe current question is sent last, so it remains the active instruction.

Before a first send, the status line estimates context plus saved history. Around 30,000 characters, the app pauses: y sends, f switches to file mode, s sends summary mode, and Esc cancels. The configured context cap is enforced independently.

08 · Chat and history

Ask deliberately, then keep the answer attached to the change.

Type a question and press Enter. For common tasks, use a quick action outside the Chat editor:

s summarizeR review riskst suggest testsb explain bug fixedp draft PR note

Follow-ups reuse the selected Git context and saved conversation. Normal letters remain ordinary text while editing a question, so typing ?, s, or R never triggers an action by accident.

Use ↑/↓ or Page Up/Down in Chat to read loaded history; Home and End jump to the oldest and newest message. Use y to copy the latest answer, Y to copy context, and e to export an answer as Markdown.

09 · Commit ranges

Review a sequence without losing it.

In Commits, press Space on the first commit, move to the second endpoint, and press Space again. The combined diff remains pinned while you browse. Files now represent the entire range; selecting one narrows that pinned diff to a file.

Range selection is intentionally modal: finish with Space, or cancel with x, before switching panes. Chat history for a range belongs only to those exact endpoints.

11 · Privacy and storage

Your repository stays in control.

The tool is read-only with respect to Git: it never checks out a branch, stages files, creates commits, or rewrites history. Chat data is local to the repository:

.git/git-explain-tui/chats/

Exports are written under .git/git-explain-tui/exports/. Every stored question and answer records the model used. Hosted models receive the selected context and conversation history; local Ollama models keep that request on your machine.

12 · Reliability and limits

What is safe, and what needs judgment.

Read-only Git browsing

Branch viewing uses a Git ref for history commands. It never runs git switch, changes HEAD, stages files, creates commits, or rewrites history. Only chats and exports are written beneath this tool’s own directory in .git.

Fast launch

The app reads up to 500 commits for the selected branch. LiteLLM is imported only after the first chat request, so ordinary browsing is not held up by model-provider initialization.

Supported platforms

macOS and Linux, including Ubuntu, are supported. Windows is not currently supported because the terminal UI relies on curses.

Model answers

Answers can be mistaken. Treat the diff and context preview as the source of truth, especially for security, migration, or production decisions.

13 · Troubleshooting

Quick answers to common problems.

“This is not a Git repository.”

Run the command inside a repository, or pass its path: git-explain-tui /path/to/repository.

Chat says an API key is missing.

Git browsing still works. Set one provider key such as OPENAI_API_KEY, or configure a local model with GIT_EXPLAIN_MODEL="ollama/…".

A patch is too large or costly.

Choose summary or file mode with m, and press v to inspect the payload before sending.

A long diff line does not fit.

Focus Diff with d, then pan with h/l or ←/→. The horizontal counter shows your position.

I changed file or context mode and my old chat disappeared.

That is expected. Conversation identity includes the commit, mode, and selected file when in file mode. Returning to the same scope resumes its saved history.

I started a range but cannot switch panes.

Range selection is intentionally modal. Move to another commit and press Space to finish, or press x to cancel.
